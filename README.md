# منصة العدساني التعليمية 2026-2027

موقع HTML/CSS/JS ثابت (بدون إطار عمل) + 5 دوال صغيرة على Vercel لإضافة الاختبارات من الموقع.
7 تبويبات: الرئيسية · العاشر · الحادي عشر علمي/أدبي · الثاني عشر علمي/أدبي · الهيئة التعليمية.
المسار: **الصف ← الفترة (الأولى/الثانية) ← المادة ← 4 تبويبات** (كتاب الطالب · بنك الأسئلة · اختبارات قصيرة · اختبارات نهاية الفترة).

## التشغيل على VS Code
1. افتح المجلد في VS Code وثبّت إضافة **Live Server**.
2. كليك يمين على `index.html` ← **Open with Live Server**.
3. في صفحات المواد يظهر تبويبا الاختبارات بوضع «معاينة محلية» تجريبي (الرفع الفعلي بعد النشر على Vercel).

## الهيكل
```
index.html · staff/ · admin/ · 404.html
10/  11-science/  11-arts/  12-science/  12-arts/
   ├─ index.html                بطاقتا الفترتين
   ├─ term1/  term2/
   │   ├─ index.html            بطاقات المواد
   │   └─ <المادة>/index.html   صفحة المادة (4 تبويبات)
pdf/<الصف>/<الفترة>/<المادة>/   ← book.pdf و qbank.pdf
assets/  css/style.css  js/  data/content.js
api/ + lib/                    ← دوال Vercel (دخول المشرف + الرفع)
scripts/build.py · scripts/check_links.py
```

## إضافة ملفات الكتب وبنوك الأسئلة
ضع الملف في فولدر المادة باسم ثابت:
`pdf/10/term1/chemistry/book.pdf` (كتاب الطالب) و`qbank.pdf` (بنك الأسئلة).
الصفوف: `10` `11-science` `11-arts` `12-science` `12-arts` · الفترات: `term1` `term2`.
أسماء المواد بالإنجليزية = أسماء الفولدرات الموجودة. إن لم يوجد الملف تظهر رسالة «لم يُرفع بعد».
على GitHub: الملف أقل من 100MB (ويُفضّل أقل من 50MB، والرفع من المتصفح حتى 25MB) — اضغط الملفات الكبيرة.

## تعديل المحتوى (من مكان واحد)
`data/content.js`: كلمة الإدارة، لوحة الشرف، من نحن، ماذا نقدم، الهيئة التعليمية، وأغلفة المواد.
الصور: ضع صورتك باسم الصورة الحالية في `assets/img/` (مثال `principal.jpg`) وتتبدل مباشرة.
الهيدر والفوتر: `js/header.js` و`js/footer.js` (يظهران في كل الصفحات).
تغيير الصفوف/المواد/الألوان: عدّل `scripts/build.py` ثم `python scripts/build.py` ثم `python scripts/check_links.py`.

## النشر: GitHub + Vercel
1. أنشئ مستودع GitHub على **حسابك الشخصي** (الخطة المجانية في Vercel لا تربط مستودعات organization) وارفع المشروع.
2. في Vercel: **Add New ← Project** ← اختر المستودع ← اترك Framework = Other ← **Deploy**.
3. من **Storage ← Create ← Blob** اختر **Public** واربطه بالمشروع (يضيف `BLOB_READ_WRITE_TOKEN` تلقائياً).
4. من **Settings ← Environment Variables** أضف:
   - `ADMIN_PASSWORD` = كلمة سر قوية للمشرف
   - `SESSION_SECRET` = نص عشوائي طويل (32 حرفاً فأكثر)
   - `LIST_CACHE_SECONDS` (اختياري، الافتراضي 900) = مدة ظهور الملفات الجديدة للطلبة
5. أعد النشر (**Redeploy**) ثم افتح `/admin` وسجّل الدخول.
6. افتح أي مادة ← «اختبارات قصيرة» أو «اختبارات نهاية الفترة»: ستظهر بطاقة **إضافة ملف جديد** وزر حذف (للمشرف فقط).

## ملاحظات
- الرفع مباشر من المتصفح إلى Blob (دوال Vercel ترفض طلباً أكبر من 4.5MB). الحد الأقصى للملف 50MB وPDF فقط.
- الخطة المجانية: Blob 1GB تخزين و10GB نقل شهرياً، وإذا انتهت يتوقف Blob 30 يوماً. وهي للاستخدام الشخصي غير التجاري.
- يرى الطلبة الملف الجديد خلال ~15 دقيقة (للتوفير في عمليات Blob)، أما المشرف فيراه فوراً.
- على الجوال يُعرض الـPDF بعارض pdf.js داخل الصفحة (يحتاج إنترنت)، وعلى الكمبيوتر بعارض المتصفح.
- الخط (Tajawal) وpdf.js وحزمة الرفع تُحمَّل من CDN، فالموقع يحتاج اتصالاً بالإنترنت.
